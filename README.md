# Alex

Static website for Milestone Premier Insurance Services. Adapted from ToddRoeller/fiorini, preserving its layout and styling.

## Pages

- index.html — Home
- quote.html — Quote requests
- help.html — Help and contact details
- privacy-policy.html — Privacy policy
- sms-terms.html — SMS terms

No build step is required. GitHub Pages publishes from the main branch, root folder. The custom domain is https://milestonepremierins.com/; DNS is managed in Cloudflare.
